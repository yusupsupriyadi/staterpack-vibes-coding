# NOTICE — Atribusi Pihak Ketiga

Repo ini me-*bundle* (vendor) konten skill yang berasal dari proyek pihak ketiga.
Repo starterpack ini hanya mengemas ulang skill tersebut agar mudah dipasang ke
project lain; hak cipta tetap milik pembuat masing-masing.

## Superpowers

Skill berikut berasal dari proyek **Superpowers** (kumpulan skill metodologi
pengembangan untuk Claude Code):

- `brainstorming`
- `writing-plans`
- `executing-plans`
- `subagent-driven-development`
- `dispatching-parallel-agents`
- `test-driven-development`
- `systematic-debugging`
- `requesting-code-review`
- `receiving-code-review`
- `verification-before-completion`
- `using-git-worktrees`
- `finishing-a-development-branch`
- `using-superpowers`
- `writing-skills`

## graphify

- `graphify` — skill untuk mengubah input apa pun menjadi *knowledge graph*
  (god nodes, community detection, query/path/explain).

## Catatan Lisensi

Sumber skill yang di-*vendor* **tidak menyertakan file lisensi** saat disalin ke
repo ini. Karena itu:

- Status lisensi tiap skill **belum terverifikasi** di dalam repo ini.
- Sebelum mendistribusikan ulang atau memakai secara komersial, **verifikasi
  lisensi upstream** dari masing-masing proyek (Superpowers dan graphify) dan
  patuhi ketentuannya.
- Jika Anda pemilik salah satu karya di atas dan ingin atribusi diperbaiki atau
  konten dihapus, silakan buka issue di repo ini.

Berkas installer, tes, dan dokumentasi (`install.sh`, `install.ps1`, `tests/`,
`README.md`, `NOTICE.md`, `.gitattributes`) dibuat untuk repo starterpack ini.
